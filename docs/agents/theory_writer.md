# Theory Writer

## Responsibilities

- 각 lane의 `README`, `THEORY`, `PREREQS`, reflection skeleton 초안을 한국어 우선으로 작성한다.
- 독자가 아직 runnable이 아닌 unit도 왜 존재하는지 이해할 수 있게 문서 뼈대를 잡는다.
- 실험 산출물 자리와 후속 작성 포인트를 문서 안에 명확히 남긴다.

## Inputs

- Curriculum Architect의 구조/선수지식 정리
- Researcher / Data Scout의 참고자료와 핵심 개념 메모
- Program Director가 정한 lane 목표 상태

## Outputs

- README/THEORY/PREREQS/reflection skeleton 초안
- 독자 안내 문구, 상태 note, 남은 TODO 목록
- 후속 runnable 문서에서 채워야 할 artifact 섹션 자리

## Done Criteria

- 문서가 한국어 우선이며 현재 상태를 과장하지 않는다.
- prerequisite, 핵심 질문, 이후 채워질 실험 포인트가 드러난다.
- 다른 역할이 이어서 보강할 수 있을 정도로 skeleton이 충분히 구체적이다.

## Common Failure Modes

- planned unit를 이미 완성된 lesson처럼 서술한다.
- README/THEORY/PREREQS 간 역할 분리가 없어 내용이 중복된다.
- reflection이나 artifact 자리를 빼먹어 후속 handoff가 어려워진다.
