# 03 Track Migration Map

기존 트랙 경로를 알고 있는 사람을 위해, 현재 루트 문서에서 사용하는 새 track path를 아래 표로 정리했다.

> 임시 전환 안내: 현재 학습 경로와 인덱싱 기준은 `00→09`이지만, 일부 downstream track README의 heading/title은 후속 cleanup 전까지 예전 번호나 제목을 잠시 유지할 수 있다. 실제 path와 순서는 루트 문서와 `docs/curriculum_status.json`을 우선 기준으로 보면 된다.

| Old Path | New Path | Note |
| --- | --- | --- |
| `02_nlp_bridge` | `03_nlp_bridge` | `02_nlp_bridge -> 03_nlp_bridge`로 이동했다. 딥러닝 트랙 `02_deep_learning`이 앞에 들어오면서 NLP bridge가 한 칸 뒤로 밀렸다. |
| `03_nlp` | `04_nlp` | `03_nlp -> 04_nlp`로 이동했다. applied NLP core가 새 딥러닝/NLP bridge 뒤에 배치되었다. |
| `04_multimodal_bridge` | `08_multimodal_bridge` | `04_multimodal_bridge -> 08_multimodal_bridge`로 이동했다. LLM, training systems, frontier labs가 추가되면서 multimodal bridge가 뒤쪽으로 재배치되었다. |
| `05_multimodal` | `09_multimodal` | `05_multimodal -> 09_multimodal`로 이동했다. multimodal applied track이 전체 `00→09` ladder의 마지막 단계로 이동했다. |
