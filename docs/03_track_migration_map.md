# 03 Track Migration Map

기존 트랙 경로를 알고 있는 사람을 위해, 현재 루트 문서에서 사용하는 새 track path를 아래 표로 정리했다.

| Migration | Note |
| --- | --- |
| `02_nlp_bridge` -> `03_nlp_bridge` | 딥러닝 트랙 `02_deep_learning`이 앞에 들어오면서 NLP bridge가 한 칸 뒤로 이동했다. |
| `03_nlp` -> `04_nlp` | applied NLP core가 새 딥러닝/NLP bridge 뒤에 배치되었다. |
| `04_multimodal_bridge` -> `08_multimodal_bridge` | LLM, training systems, frontier labs가 추가되면서 multimodal bridge가 뒤쪽으로 재배치되었다. |
| `05_multimodal` -> `09_multimodal` | multimodal applied track이 전체 `00→09` ladder의 마지막 단계로 이동했다. |
